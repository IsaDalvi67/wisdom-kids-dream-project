# Wisdom Kids Dream Project — V10 Final Update

V10 is the final planned update of the current WKDP website series.

## Included
- V9 security-state controls retained.
- Login attempt rate limiting retained.
- Recovery/lockdown donation-verification freeze retained.
- Account management and audit protections retained.
- Recovery Files portal placeholder added for linking to a separate website.

## Files portal
The external files website URL is configured in:

`recovery-vault-config.js`

Replace `FILES_SITE_URL` with the HTTPS URL of the separate files website when it is ready.

The WKDP project does not store the external files themselves.
